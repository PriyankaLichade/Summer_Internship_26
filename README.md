# Student Grade Management System

This is a simple Java GUI project developed to manage student grades in an easy and organized way.  
The application allows users to add student records, calculate performance statistics, and generate a summary report through a user-friendly interface built using Java Swing.

---

## Features

- Add student names and marks
- Store student data dynamically using ArrayList
- Generate a complete student report
- Calculate:
  - Average marks
  - Highest marks
  - Lowest marks
- Simple and interactive GUI using Java Swing

---

## Technologies Used

- Java
- Java Swing
- Object-Oriented Programming (OOP)
- Collections Framework (ArrayList)
- Event Handling

## Hotel Reservation System

A Java-based Hotel Reservation System developed to simulate room booking and reservation management. This project allows users to search rooms, make reservations, cancel bookings, and view reservation details using a console-based interface.

The project was built to practice Object-Oriented Programming concepts, file handling, and data management in Java.

## Features
Search available hotel rooms
Room categorization (Standard, Deluxe, Suite)
Make reservations
Cancel bookings
Simulate payment process
View booking details
Store booking information using file handling

Java
Object-Oriented Programming (OOP)
Collections Framework
File Handling (File I/O)
